BUILD A COMPLETE, WORKING, MOBILE-FIRST CUSTOMER WEB APP CALLED:

"HILLVIEW HOOKAH MIXOLOGY"

This is the CUSTOMER-FACING version of the Hillview Hookah Mixology application.

IMPORTANT:
- Build the actual working application, not a mockup.
- Make it run successfully in Replit.
- Make it extremely intuitive for customers who know nothing about hookah flavours.
- Mobile-first design is the highest priority.
- The experience should feel premium, modern and interactive.
- Do not ask the customer to understand percentages or technical flavour terminology.
- The customer simply chooses their taste preferences and the app recommends suitable mixes.
- The customer can then send their customized choice directly to the Hillview Hookah Expert through WhatsApp.
- Do not require login.
- Do not require an API key.
- Use localStorage where useful.
- Make the application work without a backend.

15. WHATSAPP INTEGRATION
==================================================

THIS IS EXTREMELY IMPORTANT.

The "ORDER CUSTOMISED CHOICE" button must open WhatsApp with the customer's complete selection already written into the message.

WhatsApp destination:

+917978443720

Use the WhatsApp link:

https://wa.me/917978443720?text=

IMPORTANT:
Do not hardcode the customer's selection directly into an unencoded URL.

Use JavaScript encodeURIComponent().

Example:

const message = `
Hello! My Hookah Order is:

Mix: Tropical Ice

Taste:
Fruity, Exotic, Fresh

Strength:
Medium

Flavours:
- Lady Killer (ADALYA)
- Mint (AL FAKHER)
- Mango (AFZAL)

Customization:
More Mint

Remarks:
Please prepare this mix.
`;

const whatsappUrl =
  "https://wa.me/917978443720?text=" +
  encodeURIComponent(message);

window.location.href = whatsappUrl;

The final URL should therefore contain the customer's actual selected choices after:

?text=

The WhatsApp button must work as a real clickable link/button.

Use:

ORDER CUSTOMISED CHOICE

as the exact visible button text.

When clicked, WhatsApp should open with the complete order message pre-filled.

Do not require the customer to copy/paste anything.

30. RECOMMENDATION ENGINE
==================================================

Create a reusable function:

getRecommendations(preferences)

Input:

{
  tastes: [],
  strength: "medium",
  preferredFlavours: [],
  avoid: []
}

Output:

[
  {
    name: "",
    flavours: [],
    profile: [],
    strength: "",
    description: "",
    matchType: ""
  }
]

The algorithm should:

1. Match selected taste tags.
2. Match preferred flavours.
3. Respect strength preference.
4. Avoid flavours/tags the customer rejected.
5. Favor compatible flavour combinations.
6. Create 3–5 different recommendations.
7. Avoid duplicate recommendations.
8. Provide variety.

Do not expose the algorithm or numerical matching score to customers.
