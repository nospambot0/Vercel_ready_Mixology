# Mixology PRO

**Mixology.Monster** is an interactive hookah flavour and premix guide.

Explore flavour profiles, browse premix recipes with percentages, and build a custom mix.

🌐 https://mixology.monster/

## Explore

- Hookah flavours: https://mixology.monster/flavours
- Hookah premixes: https://mixology.monster/premixes
- Mix builder: https://mixology.monster/find

This repository contains the web application powering Mixology.Monster.
